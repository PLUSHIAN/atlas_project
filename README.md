# ATLAS — Passagens Europa 2027

Monitor de passagens pessoais para dois adultos, pesquisando rotas para Barcelona, Madri, Roma, Milão e multidestinos.

O GitHub Actions fará verificações a cada **2 horas**; consultas reais terão limitação adicional para preservar a cota grátis da SerpApi. Para ativar buscas, adicione `SERPAPI_KEY` em **Settings > Secrets and variables > Actions** e ajuste SMTP para os alertas.

O repositório está **privado**. GitHub Pages gratuito exige repositório público; não alteraremos a visibilidade. O monitoramento via Actions funciona sem Pages.

A publicação do código e do workflow será concluída nesta atualização.
